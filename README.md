# UNIX
> This is a note from Lexie. In her undergrad, she used to struggle in learning Python. After she started to learn computational genomics, she started to realize that unix and bash doesn't need to be that scary as she thought.
Below is the books and websites she referenced from:
- [University of Surrey Unix Tutorial](https://info-ee.surrey.ac.uk/Teaching/Unix/unix3.html) — the first website introducing her to Unix
- [Data Carpentry Shell Genomics](https://datacarpentry.github.io/shell-genomics/06-organization.html) — also for beginner level
- [Babraham Bioinformatics Training](https://www.bioinformatics.babraham.ac.uk/training.html#unix) — helpful for Unix, R, Python, RNA-Seq, etc.
- [AstroBioMike Unix Tutorial](https://astrobiomike.github.io/unix/getting-started#accessing-our-command-line-environment) — also helpful for everything
- [Computational Genomics with R](https://compgenomr.github.io/book/reading-and-writing-data.html#reading-large-files) — textbook for R
- **[Computational Genomics PDF](https://genomics.sschmeier.com/_downloads/e9803bd48e71605daa1e34ee3ddde426/Genomics.pdf)** — this note will mainly focus on this book.
